---
id: FCT-0003
title: Resolving ambiguous requirements before generating code measurably improves the code
status: active
evidence: "ClarifyGPT (FSE 2024, arxiv.org/abs/2310.10996): asking clarifying questions first raised GPT-4's pass rate from 70.96% to 80.80%."
---

## Statement
When a code-generating model first detects ambiguity in a requirement and gets it resolved, the code it produces passes noticeably more tests than code generated from the ambiguous requirement directly.
