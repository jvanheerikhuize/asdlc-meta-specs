evidence: Dogfooding the ASDLC Meta-Specs static workspace across 16 pull requests demonstrated that automatically computing prioritized task queues, visual lineage focus, and prefilled capture links from a single index file removes manual file hunting when triaging blockers.

## Statement
Projecting the record graph into a single machine-readable index that drives a dashboard, a prioritized task queue, an interactive lineage graph, and guided capture forms allows contributors and agents to inspect blockers and propose valid multi-record edits without manually grepping files.
